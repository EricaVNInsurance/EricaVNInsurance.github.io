## Scope

Nine starter resource guides and one state hub, all noindex. Each state has state-specific resource descriptions and directly linked official references. These are NOT exhaustive state guides, county plan directories, or current Medigap-law analyses. No specific carrier plans, benefits, rates or individual eligibility claims are included. The contact dropdown now matches the nine states; preview-only submission behavior and consent wording are unchanged. No appointment, backend, API key, analytics or CRM integration was activated.
